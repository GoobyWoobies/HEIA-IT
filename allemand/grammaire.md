# Grammaire

<mark style="color:blue;">**En allemand, le verbe a une place fixe. Connais-la, et tes phrases tiennent debout.**</mark>

&#x20;

{% hint style="info" %}
**En bref**

La grammaire allemande a une règle d'or : **le verbe conjugué est en 2e position** dans une phrase normale, et **en 1re position** dans une question oui/non. Tout le reste (préfixe séparable, infinitif, participe) part **à la fin**.
{% endhint %}
